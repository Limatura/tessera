The browser extension uploads to your Tessera. Right-click an image, video, audio, link, selected text or the page itself to share it; the link is copied when the upload finishes. The popup shows upload progress and your shares, takes a note to upload, and sends you to the site to upload files. Settings hold the instance's address, sign-in through the site (or a pasted API key), and upload defaults: lifetime, download limit, and end-to-end encryption where the instance offers it. Code selected in a code block keeps its language, read from the page or guessed, so the share page highlights it. The popup opens the site, and its admin panel for an account that may use it.
