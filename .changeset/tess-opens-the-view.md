`tess` on its own opens `tess ui` on a terminal, as a full-screen tool opens on its name; piped, it prints the help. The view's welcome, shown until there is an instance, carries the tilted ticket when the screen holds it, and the install script ends by saying to run `tess`. In `tess ui`, Alt-← and Alt-→ go back and forward through the folders visited (`H` and `L` with the vim keys); Backspace still goes up one.
