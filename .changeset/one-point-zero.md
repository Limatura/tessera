Tessera 1.0. Anonymous and signed-in sharing, end-to-end encryption, the `tess` command-line client, the browser extension, webhooks and the admin panel are the feature set 1.0 stands for. From here on, a change that breaks the HTTP API (`openapi.json`), a configuration key or an upgrade from the previous version ships only in a new major version. Back up the database before upgrading; downgrades are not supported.
