自架的檔案信差。上傳一個檔案或一段文字,拿到一組取件碼,交給對方。過期或取完次數之後,內容就被刪掉。

單一執行檔,前端嵌在裡面,前面不用擺東西、旁邊不用跑東西。

## 開始

```bash
docker run -p 8787:8787 -v ./data:/data ghcr.io/limatura/tessera
```

第一次啟動會建立管理員,並且把密碼印在 log 裡 —— 只印那一次。
