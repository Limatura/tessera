# Documentation

Reasoning that does not fit next to the code. Module docs carry the _why_ for a single file; these carry the order things happen in across several, the measurements behind a decision, and the traps that cost someone a day.

`schema/` is generated by `scripts/schema-docs.py`.

## Conventions

**No issue numbers.** This repository will be recreated when it is open-sourced and the issue tracker will not survive. If a decision needs context, the context goes in the text.

**Named tests.** Where a document says an invariant is tested, it names the test so the claim can be checked.

**Measurements, not impressions.** Numbers in these files came from running something. If a number is an estimate, it says so.
